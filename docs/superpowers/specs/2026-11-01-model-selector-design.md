# 前端模型模式选择

用户已确认三档：仅本地 / 仅云端 / 本地优先、云端兜底。

在全局顶部增加可见的模式选择器，保存中禁用并显示错误；选择保存在 output/_web/model-routing.json，刷新/重启保留。不编辑 config.toml，保留用户正在修改的云端配置。显示云端文本/看图配置状态，不发真实云端探测请求。

模式只影响新提交任务的拆分镜和看图质检，不改变出图、视频、配音引擎。JobManager.submit 给每个新任务 argv 固定 --llm-mode，已排队任务和运行中任务不随后续切换变化。CLI 可用同一选项；未传选项维持现有行为。

仅本地完全不走云端；仅云端跳过本地直接请求已配置的云端，失败不回退；自动先本地后云端。显式选择自动/云端即允许使用已配置的云端，任务内覆盖 cloud.enabled，无需修改配置文件。云端配置不完整时显示原因，云端模式在无任何可用云端模型时禁用；自动仍可使用本地。

选择器采用三档下拉，沿用现有深色样式；不引入组件库和新运行依赖。与两个按钮相比能保留自动兜底；与独立设置页相比无需离开当前任务页面。

api_key_env 必须是环境变量名，误填密钥时只返回固定说明，配置 API 不回显该无效值。当前用户配置文件不修改、不提交。回归覆盖路由模式、可用性、持久化、参数白名单、队列快照、API配置脱敏；构建并目视核对前端。
